# Grapevine skills

Seven skills, one for each step Grapevine repeats for every researcher and every call. Full write-up, with before/after and results: **[SKILLS.md](../../SKILLS.md)**.

| # | Skill | What it does |
|---|---|---|
| 1 | [draft-profile](draft-profile/SKILL.md) | Turns a few sentences about someone's research into topics, plus the fields next to theirs |
| 2 | [scout-opportunities](scout-opportunities/SKILL.md) | Finds real conferences, journal calls and fellowships by reasoning about where the work belongs |
| 3 | [extract-opportunity](extract-opportunity/SKILL.md) | Reads one call page; every date and fee is copied word-for-word as proof |
| 4 | [estimate-cost](estimate-cost/SKILL.md) | Fees, flights, stay and visa, as a cost range in the person's currency |
| 5 | [find-funding](find-funding/SKILL.md) | The organisers' grants plus national funders the person qualifies for, in the order to apply |
| 6 | [compose-brief](compose-brief/SKILL.md) | "Is it worth it?": five scores with reasons, weighted by the person's goals |
| 7 | [verify-grounding](verify-grounding/SKILL.md) | Re-opens every page to confirm each date and fee is really there |

**Flow:** 1 → 2 → 3 → 4 + 5 → 6 → 7

**Used twice:** run in Claude Code to build the example shortlists in [`corpus/`](../../corpus/), and sent to Claude by the live site ([`api/`](../../api/)) as its instructions.
